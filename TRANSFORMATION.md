## 🧱 Архитектура: до → после

**БЫЛО** — на каждый запрос:
```
запрос → живой fetch 18 RSS → топ-статьи (тизеры) → Gemini → ответ
         (медленно, тизеры, слабые ссылки, ложное молчание при сбое фида)
```

**СТАЛО** — две независимые системы:
```
ВОРКЕР (раз в 30 мин, отдельный Railway-сервис)
  33 фида → fetch → DERIVE (наша выжимка + лид ≤200 + embedding) 
          → Postgres (corpus_articles + pgvector + FTS + feed_health)
          [полное тело потребляется и ВЫБРАСЫВАЕТСЯ — derive-and-discard]

ЗАПРОС (мгновенно, из корпуса)
  тема → keywords + embedding → гибрид-retrieval (RRF: вектор + лексика)
       → Gemini на реальном тексте → citation-grounding (реальные URL)
       → NLI-верификация → verified blindspot → confidence envelope → UI
```

## 📰 Источники: 18 → 34 (доказательная классификация)

Три **независимые оси** (а не один ярлык):
- **spectrum** — left … right (MBFC + eurotopics + Verfassungsschutz/ISD для крайних)
- **tier** — flagship / standard / niche (охват по IVW/AGOF 2025)
- **factual** — high / mixed / low (MBFC Factual Reporting; отдельно от политики!)

> Ключевой инсайт: **Bild = flagship (огромный охват), но factual: mixed** (таблоид).
> Оси ортогональны — нельзя мерить «уважаемость» одним числом.

**Новые (15 фидов):** Der Freitag, NachDenkSeiten, Stern, Frankfurter Rundschau,
Berliner Zeitung, RND, Deutsche Welle, MDR, NZZ, WirtschaftsWoche, Cicero,
Nius, Apollo News, Epoch Times DE, Achgut.

Low-factual издания (Nius, Epoch Times DE, NachDenkSeiten) **включены для полноты
спектра, но помечены** — дают покрытие, но не вес в фактах. Каждый рейтинг несёт
`rating_source` (provenance) + confidence; пограничные (≤0.65) флагуются на ревизию.

## 🔴 Три «красных» проблемы достоверности — закрыты

1. **Ложное молчание** от сбоя фида → `feed_health` + 3-уровневая модель:
   `camp_silent` (реальное замалчивание) / `flagship_silent` («писали только мелкие») / `unknown` (фид сломан — не обвиняем).
2. **Непроверяемые «эксперты»** → NLI-верификация утверждений по исходному тексту.
3. **Асимметрия покрытия** → reach-взвешенная нормализация по `source_ratings`.

---

## ⚖️ Легальная модель (derive-and-discard)

Полное тело статьи — **транзитный вход**: используется только чтобы вывести
нашу выжимку (`our_summary` ≤600) + короткий лид (`short_lead` ≤200) + embedding,
затем **выбрасывается**. В БД нет колонки с полным текстом. Это держит нас вне
зоны German Presse-Leistungsschutzrecht (§87f UrhG / EU DSM Art. 15).

---

## 👁️ Что теперь видит пользователь (Шаг 13)

Панель достоверности над анализом:
- **Confidence 0-100 + band** (🟢 high / 🟡 medium / 🔴 low), цветной
- **Quellen-verifiziert: X/Y** — статьи с проверяемым первоисточником
- **Lager abgedeckt: n/5** + число источников
- **⚠️ Contradiction-предупреждение**, если утверждение не подтверждено
- **Баннеры молчания:** 🔴 Verschweigen / 🟡 Leitmedien still / ⚪ Nicht bewertbar
- Полная локализация **de / en / ru**

## 🛡️ Процесс и безопасность

- ✅ Каждый шаг — тесты до коммита, коммит на `dev`, отчёт «было/стало»
- ✅ Корпус-врезка **за флагом** `CORPUS_ANALYSIS_ENABLED` (по умолчанию off → старое поведение байт-в-байт)
